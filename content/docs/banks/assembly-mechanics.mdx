The mechanical catch-all: brackets, structural hardware, assembly kits and build supplies, everything that isn't a screw, organised in a labelled coordinate grid.

<ComponentBank id="assembly-mechanics" />

## Finding things

Match a physical slot's row number and column letter to the grid above to see what belongs there. Cells with extra detail list the individual items inside.

<Callout type="info">
  Empty slot, or the part you need isn't there? Submit a component request using the request button on the [filament page](/docs/filament) as a template, or tell exco directly; requests land in the ops dashboard queue.
</Callout>
