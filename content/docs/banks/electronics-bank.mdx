One map for the whole electronics workstation: every box is a cabinet or drawer you can walk to, labelled with its code (rows 1–13, letters A–B, then the thin C–I drawers below), and the text inside says what's in it. The cabinets from 8 onwards hold the SMT towers, whose drawer codes (R/C/D/Q/U) are decoded in the value charts further down; drawers 5B and 6B hold the printed sensor and MCU boxes.

![How the electronics workstation looks on the bench — cabinet codes 1A to 13B, with the 5B and 6B drawers labelled.](/banks/electronics-workstation.webp)

## Finding things

Search the grid for a part name — `heatshrink`, `0805`, `Modules` — and matching drawers light up with their coordinates. Full screen expands the whole bank; merged boxes mirror the physical bins, one box per drawer.

<Callout type="info">
  Empty slot, or the part you need isn't there? Hit **Request a restock** above the grid and pick the part (or "Something else…"); it lands in exco's ops dashboard queue. No account needed.
</Callout>

## The 5B and 6B boxes — sensors and MCUs

Drawers 5B and 6B each hold three printed boxes side by side. The sensor box (1) is one tall unit that spans both drawers — `1aa` faces 5B and `1ba` faces 6B — printed with the same category list; the module and MCU boxes sit separately in each drawer.

## SMT Drawer Values

The SMT towers (cabinets 8 onwards on the grid above) are organised by component letter and drawer code — a drawer labelled `R39 (0402)` on the map is decoded here. Resistor values follow the standard E-series: E24 ({1.0, 1.1, 1.2, 1.3, 1.5, 1.6, 1.8, 2.0, 2.2, 2.4, 2.7, 3.0, 3.3, 3.6, 3.9, 4.3, 4.7, 5.1, 5.6, 6.2, 6.8, 7.5, 8.2, 9.1} × each decade), with E12 and E6 subsets for the coarser drawers.
