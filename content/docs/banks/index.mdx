Parts live in three labelled banks. Each page below shows a live grid of what's where, with rows and columns matching the physical layout, so you can go straight from the wiki to the right drawer.

- [Electronics Bank](/docs/banks/electronics-bank): dev boards, sensors, modules, wire
- [Assembly & Mechanics](/docs/banks/assembly-mechanics): brackets, hardware, build supplies
- [Screw Bank](/docs/banks/screw-bank): M2–M6 fasteners, bearings, motion parts

If a bin is empty or the part you need isn't stocked, submit a component request and exco will restock it. The [filament page](/docs/filament) has the request flow.
