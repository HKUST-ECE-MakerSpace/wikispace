Parts live in three labelled banks. Each page below shows a live grid of what's where, mirroring the physical layout so you can go straight from the wiki to the right drawer. Search a bank to light up matching drawers, open the grid full screen for a proper look, and request restocks right from the page.

- [Electronics Bank](/docs/banks/electronics-bank): dev boards, sensors, modules, wire
- [Assembly & Mechanics](/docs/banks/assembly-mechanics): brackets, hardware, build supplies
- [Screw Bank](/docs/banks/screw-bank): M2–M6 fasteners, bearings, motion parts

Empty bin or missing part? Every bank page has a **Request a restock** button that feeds exco's ops dashboard queue.
