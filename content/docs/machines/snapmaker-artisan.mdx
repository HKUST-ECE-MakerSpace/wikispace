The Artisan is three machines in one frame: an FDM printer, a 40W laser engraver/cutter, and a CNC router, chosen by swapping toolheads. Swapping is the easy part; what gets skipped is the recalibration afterwards, which is how alignment errors happen. Run the calibration sequence every time you change toolheads or bits.

## Quick Start

<Steps>
  <Step>Power on the machine and wait for the touchscreen to fully boot.</Step>
  <Step>Select the correct module (Laser or CNC) from the touchscreen menu.</Step>
  <Step>Install the appropriate toolhead (laser module, or CNC module with bit).</Step>
  <Step>For laser: install the laser engraving/cutting platform and secure the material with clamps or tape.</Step>
  <Step>For CNC: install the CNC carving/cutting platform and clamp the material firmly.</Step>
  <Step>Run the auto bed leveling / platform height calibration sequence.</Step>
  <Step>Set the work origin (X, Y, Z) for your chosen module on the touchscreen.</Step>
  <Step>Use the Boundary Check feature to verify the machining area.</Step>
  <Step>Start the job at low power/speed first to confirm alignment.</Step>
  <Step>Never leave the machine unattended during operation.</Step>
</Steps>

## Troubleshooting

<Accordions>
  <Accordion title="Laser Not Cutting Through">
    Check the focus height first, then increase passes; a dirty lens loses power, so clean off any residue.
  </Accordion>
  <Accordion title="CNC Bit Breaking">
    Reduce the depth per pass and check the feed rate. Confirm the material is clamped firmly before restarting.
  </Accordion>
</Accordions>

## Repair Guides

<Accordions>
  <Accordion title="Laser Lens Cleaning">
    **Difficulty:** Easy · **Tools:** Lens cloth, isopropyl alcohol

    Power off, remove the laser module cover, wipe the lens gently in one direction, and reassemble.

    <Callout type="warn">Never touch the lens with bare fingers.</Callout>
  </Accordion>
  <Accordion title="Change Tool Bit (CNC)">
    **Difficulty:** Easy · **Tools:** 14mm open end wrench, 17mm open end wrench, replacement bit

    Power off the machine and loosen the collet nut using the wrenches. Remove the old bit, insert the new one fully into the collet, and tighten the nut securely. Power on and run the toolhead calibration.

    <Callout type="warn">Ensure the bit is fully inserted and tight. Loose bits can break or damage the machine.</Callout>
  </Accordion>
  <Accordion title="Recalibrate Settings After Tool Change">
    **Difficulty:** Medium · **Tools:** None (touchscreen only)

    Power on the machine and open the calibration menu on the touchscreen. Run platform height calibration, set the work origin for the current toolhead, then run a test boundary check to verify alignment. If you're on the laser, run laser focus calibration as well.

    <Callout type="warn">Always recalibrate after swapping toolheads or bits to prevent alignment errors.</Callout>
  </Accordion>
</Accordions>

## Rules

- Never leave laser or CNC jobs unattended; stay with the machine throughout the task.
- Always use air assist / dust extraction when operating the laser module.
- Wear safety glasses when operating the laser module.
- Secure material fully with clamps before starting any CNC or laser job.
- Ensure the Enclosure door is closed and stays closed during laser operation.
- Keep the emergency stop button within easy reach at all times.
- Report any calibration drift, alignment issues, or unusual noises to exco immediately.
- Clean the laser lens before each use with a lens cloth and IPA.
- Only use authorized bits and tools for CNC operations.
- Log all jobs (material, duration, username) in the workshop registry.
- Only exco can change advanced settings or update firmware.
- Do not use highly reflective materials for laser engraving (except 304 stainless steel and anodized aluminium).
