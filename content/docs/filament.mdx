## Before you print

Check the table for your material **and** colour before you slice; the machines have verified profiles per material (see each [machine page](/docs/machines)). Also make sure the stock column shows enough rolls for the whole print, not just the first layers.

## Low-stock alerts

Rows highlighted in amber are running out: 2 rolls or fewer, marked "· low". If the filament you need is low, or already gone, use the **Request filament** button above the table. It sends a restock request straight to exco's ops dashboard, and the inventory updates once the request is fulfilled.
