## Reporting an issue

Every machine page opens with a **live status badge**; check it before you plan work around a machine. If a machine misbehaves (a clog, grinding, a failed print, an unusual noise), report it to exco the same day rather than assuming the next person will deal with it. Ask the exco on duty, or message the WhatsApp group (contact details to be added). The **QR** button next to the badge opens that machine's page on your phone, which is useful when you're standing at the machine and need the specs.
