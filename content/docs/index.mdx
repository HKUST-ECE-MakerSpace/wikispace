## Reporting an issue

Every machine page starts with a **live status badge** — check it before you plan work. If a machine misbehaves (clog, grinding, failed print, unusual noise), report it to exco right away; the **QR** button next to the badge opens that machine's page on your phone so you can check specs on the spot.
